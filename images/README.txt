Healthy Meals and Recipes - images folder
==========================================

This website does not use any locally stored images.

All photographs are loaded directly from Unsplash (https://unsplash.com)
using image URLs in the HTML files and in js/script.js. Unsplash images
are free to use under the Unsplash License.

Every image has meaningful alternative (alt) text for accessibility.

Icons and the logo are created with Unicode characters, and the favicon
is an inline SVG data URL, so no image files are required.

This folder is included to keep a standard project structure. If you
later want to use your own photographs, place them here and link to them
with a relative path, for example:

    <img src="images/my-photo.jpg" alt="Describe the photo here">
